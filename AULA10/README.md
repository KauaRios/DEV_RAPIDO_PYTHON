# Aula 10

A maior parte da aula foi dedicada à continuação do código da [aula 9](../AULA9/), especialmente os exemplos de classes, dataclasses e banco de dados. Por isso, essa parte permanece junto dos arquivos da aula 9.

Também tivemos uma introdução ao Tkinter. O arquivo [primeira_janela.py](primeira_janela.py) cria uma janela, define seu título e tamanho e inicia o loop de eventos.

Para executar a partir da raiz do repositório:

```bash
python AULA10/primeira_janela.py
```

É necessário ter o Tkinter instalado e um ambiente gráfico disponível.
